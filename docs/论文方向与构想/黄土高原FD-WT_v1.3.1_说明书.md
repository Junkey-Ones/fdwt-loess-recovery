# 黄土高原 FD-WT v1.3.1 说明书

## 1. 一句话理解课题

本课题不是单纯寻找更多“骤旱—暴雨”事件，而是回答：**黄土高原骤旱在最低点后如何恢复，极端降水在何时接续，以及事件前冠层结构和深层土壤水是否对应不同的恢复／急转路径。**

## 2. 为什么 v1.3.1 与 v1.2 的叙事不同

v1.2 把 E1b 和 P/F 集合关系推到前台，容易使论文变成“两个定义有多少重叠”。v1.3.1 将恢复动力学重新放回第一核心：

1. 先描述 RT、ΔSMP、RR，并用右删失模型保留未恢复事件；
2. 再研究 F_R 和 Lag；
3. 最后检验事件前 LAI 与深层水的关联和效应修饰；
4. P/F、Jaccard、F_Z、DFAI 退回质控或补充。

这不是润色变化，而是主 estimand、结局排序和论文主问题的纠正。

## 3. 两条路线如何配合

### 路线一：必须完成的独立主研究

**数据质控→骤旱事件库→恢复动力学→F_R／Lag→LAI／深层水模型→跨产品稳健性。**

即使路线二完全退出，路线一仍能形成完整论文：有过程、有结局、有事件前条件、有不确定性检验。

### 路线二：可拆卸的三出口扩展

将全部骤旱放入 12 候随访：

- A：非急转恢复；
- B：湿润急转恢复；
- C：持续未恢复。

主模型是离散时间原因别风险，不是普通多项 logit。右删失单独处理；“下暴雨但没恢复”仍留在未恢复风险集。路线二只补充离场类型与时间，不增加生态后果。

## 4. 年份到底怎么用

不是全课题只能 2003—2023，而是四层并存：

- 总体事件：2000—2023；
- LAI 完整年：2003—2023；
- LAI 五年暴露模型：2008—2023；
- LAI 与 NDVI 共同样本：2008—2023。

2008 年事件的暴露窗是 2003—2007。早期事件继续用于恢复和急转，不因缺 LAI 被删除。

## 5. 最关键的十个参数

| 项目 | 主设置 |
|---|---|
| 网格／时间 | 0.1°；每年 73 候 |
| 骤旱 | SMP >40%→<20%；下降≥5 百分位／候；持续≥4 候 |
| 恢复 | 最低点后首次>20%；40%终止敏感性 |
| 恢复指标 | RT=t_e−t_min；ΔSMP；RR=ΔSMP/RT |
| P-term | [t_min,t_e+2]；P95且>1 mm |
| F_R | [t_e−1,t_e+1]；P95且>1 mm；分pre／sync／post |
| F_Z | W1<0、W2≥0.5；仅补充 |
| 时间指标 | Lag_P=t_P95−t_min；Lag_FR=t_w,R−t_min；Offset_FR=t_w,R−t_e |
| 植被暴露 | 事件前五年 LAI 均值与 Sen 斜率；NDVI 稳健性 |
| 路线二 | t0=t_s；H=12候；6／18候敏感性 |

## 5.1 v1.3.1 只增加的必要限制

- Q1 只代表总持续≥4候的合格事件；恢复风险统一为 t0=t_min、随访12候，并区分行政／缺失删失。
- F_R_post 只表示恢复后降水；恢复速率／幅度的主对比只用 pre＋sync。
- Lag_P、Lag_FR 和 Offset_FR 不再混用。
- Q3 除事件数外，按 `grid_id×year` 审计独立 LAI 暴露簇；交互同时报告 link 尺度乘积项和实际概率／风险尺度边际效应。
- GLDAS 重网格不增加信息，另做原生0.25°复算；站点、F_Z、路线二和环流均为条件性输出。

## 6. 最短可执行路径

1. 固化研究区、产品版本和原始文件清单；
2. 原生 QC、单位／符号、候聚合、土层计算、面积加权；
3. 建物候窗和各产品独立气候态；
4. 建全部事件库，保留右删失；
5. 输出恢复指标、F_R、Lag 和样本流图；
6. 连接 2008—2023 的五年 LAI 暴露与前 4 候深层水；
7. 先审计 n、结局数、空间块和 EPV，再冻结模型自由度；
8. 跑路线一主模型、四套产品组合和规范曲线；
9. 按门槛决定路线二为描述、探索还是退出；
10. 独立复算、核对偏离日志后再写论文结论。

## 7. 哪些结果可以说，哪些不能说

- 可以说：“事件前 LAI 趋势与恢复风险存在条件关联，且该关联随深层水状态变化。”
- 不能说：“绿化导致骤旱更快恢复”或“深层水库被证明是因果机制”。
- 可以说：“CHIRPS 替换后方向一致。”
- 不能说：“F_R 与 F_Z 相互独立验证。”
- 可以说：“H 时仍持续未恢复。”
- 不能说：“所有 C 都已转为常规干旱。”
- 不显著只能写证据不足；等价必须满足预设区间界。

## 8. 创新如何判断

LAI 替换、P95 窗口、双分支、候尺度和三出口本身都不是高创新。较有价值的贡献需要数据支持：

1. 恢复—急转时点—事件前冠层／深层水形成闭合且跨产品稳定；或
2. 三出口揭示路线一看不到的离场时间和持续未恢复路径。

若最终只有频率、趋势和地图，创新偏弱；若效应修饰或离场路径稳定，创新可达中等至中等偏上，但仍不能保证特定期刊发表。

## 9. 五份文档怎么用

- **详细技术手册**：实际执行时查变量、公式、参数和失败退路；
- **预注册文档**：冻结主结局、检验家族、样本排除和偏离纪律；
- **模块化思路理解**：查每个模块输入、输出、负责人、接口和验收；
- **权威文献引用解释**：查每个方法从哪里来、是否尺度匹配、哪些内容不能照搬；
- **本说明书**：用于快速恢复整体思路和写作边界。
