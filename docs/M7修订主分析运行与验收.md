# M0—M7 修订主分析运行与验收

从项目根目录打开 PowerShell，按顺序执行。正式运行应采用未使用的别名。4/5 是查看两方案调整效应后确定的 Q3 修订主分析，5/5 是原预设主分析。两个身份分别冻结。若使用向导，先单选 M0 正式冻结，再选 M7，以相同别名、产品和规格续接。

```powershell
$py = ".\.venv\Scripts\python.exe"
$relaxed = "2026-11-18_M7修订主分析4of5"
$strict = "2026-11-18_M7原预设主分析5of5"
& $py -m workflow.run_module M0 --freeze --run-alias $relaxed --variant lai_four_of_five
& $py -m workflow.run_module M7 --run-alias $relaxed --variant lai_four_of_five
& $py -m workflow.run_module M0 --freeze --run-alias $strict --variant main
& $py -m workflow.run_module M7 --run-alias $strict --variant main
& $py -m notebooks.m7_compare_schemes $strict $relaxed
```

每条命令成功后再执行下一条。上述命令走完整依赖链。本次 M3 科学判定和 M6 交接字段已更新，请使用完整依赖链和新别名，旧 M3—M6 不适用于本次修复。

- outputs/<别名>/reports/m7_acceptance.md 给出方案和逐模型状态。支撑不足未拟合、仅放行点估计、条件未触发各自记录，失败次数计入分母。
- outputs/<别名>/tables/ 发布模型及区间明细，nonforest 位于 sensitivity_model_* 表。按基线地类限定 Q3，其他协变量与同规格主模型一致。
- logs/<别名>/module_io_M7.json 的 details.q1_risk_check 给出各随访版本逐候计数，details.four_year_support 按实际缺年第几位、事件年及地类汇总恰四年暴露。n_raw 包括研究期外事件，n_period 限于暴露分析年份，n_event 为通过所选方案的事件；n_recovery_L/I 和 n_fr_L/I 分别按两种结局与完整暴露筛选。RT 单位为候，ΔSMP 为百分位点，RR 为百分位点/候。
- 独立覆盖率模拟使用合成事件史和生产曲线函数。运行 `& $py -m notebooks.q1_full_coverage`。需要先试验运行成本时，使用 `--repetitions 1`。正式诊断沿用配置中的重复次数和空间、年份及交叉相关情景。逐候输出覆盖率、可用次数、不可用次数和 Monte Carlo 区间。单次试运行只验证流程。
