## 使用中文向导

在项目根目录 PowerShell 执行：

```powershell
.\.venv\Scripts\python.exe -m workflow.run_module
```

1. 选择“指定模块”，输入 `M0`。
2. 输入未用过的新别名，例如 `2026-11-15_从头复算`。后续全部使用该别名。
3. 选择主产品组合 `era5land__era5land`，在“选择分析方案”面板选“5/5年严格方案（主分析）”或“4/5年方案（预设敏感性）”，资源可选自动。
4. 最后选择“正式冻结 M0”。确认实际审计及冻结成功后再继续。
5. 再次启动同一向导，选择“指定模块”，输入 `M7`，使用刚才的同一别名、产品组合和变体。
6. 核对计划为 M0、M1、M2、M3、M4、M5、M6、M7，然后选择“执行已选模块”。已有同别名 M0 回执用于续接；其余模块按依赖计算。

不要选择“路线一主分析”作为只跑到 M7 的快捷方式，该选项还会包含 M9、M10。不要复用旧主分析别名来覆盖原冻结结果。遇到失败应先查看同别名日志，按入口的续跑能力处理，不能手动清空冻结目录来绕过检查。
