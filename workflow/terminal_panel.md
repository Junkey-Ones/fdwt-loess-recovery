# 终端面板

组件位于 `workflow.terminal_panel`。从项目根目录运行 `.\.venv\Scripts\python.exe -m workflow.run_module` 进入中文向导。五步依次为运行范围、运行版本、数据与规范、资源与显示、确认计划。输入「返回」可回到上一组设置，输入「帮助」或「退出」打开提示或结束向导。确认页可以直接修改指定组，保留已填值并重新核对执行条件。向导使用终端原生输入。

运行中按 `1` 看总览、`2` 看模块状态、`?` 看帮助，`Ctrl+C` 中断。宽终端并列显示，窄终端纵向排列。文本模式输出阶段变化、每 30 秒摘要及最终状态。

## 后续模块如何接入

- 编排入口用 `WizardPanel(title)` 的上下文管理器收集运行控制选项。每道题调用 `panel.ask(prompt, check, default, details=...)`。校验函数返回有效值，输入无效时抛出带中文说明的 `ValueError`。
- 单选题调用 `panel.menu(prompt, options, default, section=...)`。每项提供内部值、中文标签和用途说明，界面自动编号并标记默认项。提交前的确认题汇总模块顺序、数据来源、规范和四类输出路径。
- 运行阶段由编排入口统一管理 `LiveStatus(mode, render)`。先调用 `start()`，在 `finally` 中调用 `close()`。渲染读取线程安全快照。模块通过 `workflow.progress.emit` 上报阶段、计数和状态，仍兼容旧三参数回调。
- `auto` 在支持的终端启用 Rich，重定向时降级为逐行提示。`panel` 要求终端支持光标更新，`plain` 使用逐行输出。面板和提示使用标准错误，结构化结果使用标准输出。

Windows 下建议从 Windows Terminal 启动。向导运行在备用屏幕，答题结束后切换到运行进度显示。

阶段速度基于 30 秒窗口内至少三次有效工作量更新。总估时至少需要两条签名匹配的成功记录。计时记录及 ETA 样本覆盖、绝对误差中位数写入本机运行目录的 `progress_*.json`。没有依据时显示暂无法估算。见[事件与估时](progress.md)。
