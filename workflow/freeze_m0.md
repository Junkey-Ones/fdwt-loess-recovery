# M0 正式冻结与运行登记

统一入口调用本脚本，在审计通过后封存协议快照，并以协议版本、输入哈希、代码哈希和种子标识生成运行编号。

输入包括 M0 审计、配置、协议原文、边界和偏离登记，以及实际工作树内的 Python 文件和 Git 提交。参数哈希同时覆盖冻结输入、产品组合和规范变体。M1 可变验收台账独立留在审计日志中。

冻结记录及身份写入 `outputs/{run_alias}/`，模块状态、偏离副本、身份和模块回执写入 `logs/{run_alias}/`。运行索引为 `metadata/run_index.csv`。相同输入用同名续跑只补齐缺失产物，遇到内容不一致须使用新别名。

从统一入口选择 M0，再选择「正式冻结 M0」。高级入口为 `python -m workflow.run_module M0 --run-alias 2026-11-10_M0冻结 --freeze`。

这是内部预注册运行冻结。区域生产仍需 M1 数据验收，M1 及后续模块的正式执行待接入。
