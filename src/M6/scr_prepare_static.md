# 土壤和地形协变量

M6 前置读取 SoilGrids 六个原生 GeoTIFF 和 NASADEM HGT、NUM 瓦片。三层完整的砂、黏粒按厚度加权到 0–30 cm，以质量百分比输出。六层同时为零暂按缺测处理并在运行进度记录数量，该处理属于本地文件的保守解释，需保留至资料复核。SoilGrids 使用实文件仿射参数和等积投影交叠面积。

NASADEM 在原生 posting 上用邻接瓦片补齐邻域，按局部二次面拟合派生坡度，再聚合坡度和高程。研究区外缘缺少邻接瓦片时，用剩余有效邻点拟合，秩不足时该像元坡度为空。输出保留覆盖率、坡度算法和 NUM 来源面积比例。

完整邻域直接在 3×3 滑动窗口视图上应用同一组二次拟合系数。含缺测邻点的窗口按有效点掩膜使用相应的拟合系数。

NASADEM 每次读取一组主瓦片及其邻域。在同一主瓦片内，多个 CPU 线程共享只读高程和来源数组，分批计算格点汇总。主线程按原有顺序归并。线程数取统一入口生效的工作进程上限，面板显示本阶段的线程数与瓦片内进度。
