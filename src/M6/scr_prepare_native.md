# M6 原生输入前置

由统一入口在 M6 正式计算前调用。已登记且通过哈希核验的外部交接可直接使用，其余表从本地原始数据生成。生成的 Parquet 与 M6 其他产物一并原子冻结，M6 回执记录原始文件哈希。缺少原始产品时，M6 仍可生成已有数据支撑的描述性结果。

依赖 pyhdf、rasterio、shapely 和 pyproj。已有 M5 修订回执的运行可沿用同一别名。代码及配置变更从 M6 单独登记，上游沿用已冻结回执。

终端面板显示原始文件哈希、SoilGrids 格点、NASADEM 瓦片格点、LAI 活跃候和 HDF 文件的处理进度。LAI 合成时，明细另显示当前年份、瓦片及瓦片内格点进度。超过 30 秒无新上报时，面板显示距上次上报的时间及这段时间内主进程累计使用的 CPU 时间。等待磁盘读取时，CPU 时间可能增长很少。
