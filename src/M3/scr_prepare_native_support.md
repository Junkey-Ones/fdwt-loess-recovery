# M3 原生地类和物候格点支撑

将原 `metadata/local/build_grid_support.py` 的已使用构建算法接入正式 M3。科学计算位于本模块，哈希、运行身份、日志及原子发布由 `workflow.run_downstream` 管理。

输入：同一运行的M2格点表、登记边界、统一配置，以及 `data/raw/modis/MCD12Q1/V061`、`MCD12Q2/V061` 原始年度HDF。地类年份来自mask配置；物候年份来自研究时期。允许年份子目录，拒绝重复键、部分缺年或不一致的两产品瓦片集合；缺少整个覆盖瓦片由面积闭合检查阻断。

没有已验收的 `grid_support` 登记时，统一入口自动生成。已登记标准表继续走原来的来源哈希核验。错误或缺失的已登记文件不会被静默替换。无登记也无原始数据时保持既有缺输入退出行为。

输出：`data/frozen/downstream/{run_alias}/M3/grid_support.json` 和 `grid_support_audit.json`，连同既有M3表及回执一起原子发布；原生来源路径/哈希记录于 `module_io.json`。不改写共享补充输入登记，不依赖手动预先运行本地脚本。输入变化或已冻结代码变化须使用新的运行身份。

算法保持原生正弦投影面积积分、逐像元多年地类排除、基线众数和面积主导地类、Best/Good物候周期日期面积加权中位数。有效年回退仍由 `scr_prepare_support` 完成。非交叠瓦片跳过解码，全部格点必须通过面积闭合。该接入不改变研究区或科学门槛。

运行：统一入口选择M0正式冻结新别名后，使用同一别名选择M3或M7。不要直接调用本脚本启动生产。

限制：当前支持C6.1既定SDS结构和北纬东经研究区；不是任意全球投影网格通用实现。原生物候采用总体QA Best/Good，详细QA仅作审计。已登记外部支撑的科学验收责任不由本前置替代。

2026-11-15验收：全套58项测试通过；从森林、草地、耕地各选一个实际格点，使用地类2001–2023年及物候2003–2023年原始HDF重新计算，与历史grid_support逐字段一致（浮点绝对差小于1e-10），面积闭合最大相对误差1.90e-12。这里只验收三个真实格点，未替用户运行全域生产M3。细节见 `metadata/local/m3_native_smoke_20261115.json`。
