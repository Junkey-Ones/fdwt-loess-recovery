# MX 分析枝干清理

从项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m src.MX.scr_remove_run
```

打开后，桌面面板会列出已登记的运行和标准产物目录中的未登记枝干。点击一行切换勾选，也可用空格键切换当前行。勾选一个或多个枝干，点击「确定」查看待移除的绝对路径和索引操作。确认窗口默认聚焦「取消」，点击「移入回收站」后才会回收目录。

脚本清理该别名的结果、日志、中间数据和冻结产物，包括运行索引登记的对应路径。其他别名、原始数据、代码、配置和协议留在项目中。正在运行的别名、越界路径、符号链接和目录联接会被拦截。

Windows 回收站操作成功后，脚本从 `metadata/run_index.csv` 删除该别名的索引行。若部分目录回收失败，索引行保留，终端显示已回收及剩余路径。修复原因后可重新输入同一别名确认剩余范围。

要恢复已回收的目录，请在 Windows 回收站使用「还原」。如需恢复正式运行身份，还要从备份或 Git 中还原该别名的索引行。
