# FZ及DFAI探索补充

由M7统一入口读取M5事件、分支和恢复轨迹及M6暴露。FZ阳性必须找到FZ自己的首个接续候，按该候活跃性确定资格，不能继承FR接续候的资格。未知判定保留未知；活跃性未知和明确出窗分别计数。创建独立结局视图复用既有logit拟合器，主事件对象不改写。

输出Q2背景调整FZ logit及Q3 L/D/I三模型，分析ID明确为fz；与FR用相同支撑和不确定性方法，独立sensitivity_*表、不进入主Holm家族。FZ格点年和区域/块比例使用自身已知分母并列输出。

DFAI分别使用FR/FZ分支自己的W1/W2和已冻结强度值，仅在条件A、该分支接续候活跃且严格E2a资格有效时描述；强度限制不删除FZ发生模型的阳性。给出分支区域均值/中位数、IQR、分母及区间。发生分支和严格强度分支不能混称同一总体。它们依赖再分析水量收支，不能单凭模型结果作机制或因果验证。数据缺失时独立条件性跳过，不能默认为零。
