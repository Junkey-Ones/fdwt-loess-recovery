# 主模型支撑与解释诊断

由统一M7入口读取主模型清单、系数和配置，发布`model_diagnostics`。不修改主p值或模型。

- 按技术手册，n_eff<50保留线性；50≤n_eff<100仅参考；≥100标记需要形状分析，未自动冒称GAM已拟合。
- logit的预设OR界转为log尺度，交互对应比值比之比；连续中位数对比采用实际模型结局SD的±0.10。cloglog不擅自把OR界移作恢复风险界，标记无预设界。只有整个联合区间位于界内才报告等价范围内；区间缺失或不显著不能推断无效应。
- 报告区间宽度近似MDE：以联合区间距点估计较远的一侧/z反推保守尺度，乘以Bonferroni家族临界值加目标功效分位数。它是正态/固定标准误条件下的设计敏感度近似，不是计算观察功效，不是有限样本功效保证，也不改变原Holm检验。字段明确注明近似方法。
- 原单位、link尺度和每模型标准化均沿用主模型，不能把不同单位的MDE直接比较。
