# M7单因素模型敏感性

输入为M5事件、M6暴露和M7各自重建的风险表、配置及身份；由统一入口运行并写入独立`sensitivity_*`表。所有模型仍使用相同协变量、支撑门槛、种子和500次空间自举。输出包含失败与样本支撑，不产生主检验p值。

- Q2均值模型用最小二乘，pre/sync与非FR样本与中位数主模型一致，post仍排除。
- Q3共同样本限L/D/I暴露完整交集，分别在两个结局队列内比较，不是NDVI共同样本。
- 每暴露簇抽一事件先按该模型结局及协变量完整性筛选，再按簇和事件ID排序，用配置种子均匀选取；只用于L/I。选择固定后再做空间自举，不嵌套重复抽事件。
- 逆簇大小权重以模型实际纳入样本计算，同一事件整条风险历史共用该权重；空间自举乘以该权重，聚类得分和信息矩阵同步加权。连续变量标准化和深层P25/50/75仍来自未加权事件样本，使单位定义明确；边际平均改用簇等权目标。
- 6/18候及完整随访、限活跃窗仅重拟合恢复模型。传入各自风险表，不截取12候表冒充18候。

主结果表不增加模型或检验。敏感性完整区间标记`sensitivity_interval`，失败保留原原因。主样本标准化随样本变化，跨版本数值需结合各自标准化字段解释。本实现不等于跨产品或NDVI敏感性已完成；这两项需要不同的上游表。

年份分类敏感性以最早事件年为参照，用分类项替代year_centered_2000；土壤/地形精简按手册删除砂粒和坡度、保留黏粒及高程，其他核心项不变。二者分别重拟合Q2/Q3，不交叉组合或按显著性筛选。

Q3连续结局次级分析以全部已恢复条件A事件为队列，分别对RR和delta_SMP拟合L/D/I中位数回归，保留post及未知FR（不以FR可判定性筛选）。连续结局没有“阳性/阴性臂”，这两个计数留空，支撑按事件数、块、暴露簇和原n_eff门槛核对。I模型边际值是样本平均的条件中位数预测，不是均值或概率；predicted_response/response_difference使用原量纲，原概率字段留空。六模型不加入主检验家族。
