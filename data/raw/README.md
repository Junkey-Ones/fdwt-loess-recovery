# 原始数据

本目录存放黄土高原骤旱恢复与极端降水接续研究的原始输入。2026-11-10 盘点共 **17,461 个文件，约 245.24 GiB**。统计排除本 README，包含压缩包、已解压副本和 GLEAM 下载辅助文本。覆盖范围主要依据文件名，ERA5-Land 另核对了月键连续性并抽查首末文件元数据。正式使用以 M1 实文件验收为准。

## ERA5-Land 主分析输入

| 子目录 | 文件数 | 本地覆盖 | 抽查字段与用途 |
|---|---:|---|---|
| `era5_land/instant` | 277 | 2001-01 至 2023-12 月文件，另有 2024-01-01 小时数据 | `swvl1`–`swvl4`、`t2m`。前三层用于 0–100 cm 根区土壤水，第四层用于 100–289 cm 深层水。 |
| `era5_land/accumulated` | 277 | 2001-01 至 2023-12 月文件，另有 2024-01-01 小时数据 | `tp`、`e`、`pev`。2024-01-01 补档还含 `sro` 和 `ssro`。 |
| `era5_land/runoff_components` | 288 | 2000-01 至 2023-12 月文件 | 首末月均见 `sro` 和 `ssro`，用于水量平衡。 |
| `era5_land/surface_runoff` | 276 | 2001-01 至 2023-12 月文件 | 单独保存的 `sro`，与双分量批次重叠。M1 核对两批次后选定正式来源。 |

四个子目录各自的月键连续。两份 2024 年 1 月文件的时间坐标均为 **2024-01-01 00:00–23:00 UTC**，可用于检查 2023 年末边界。主土壤水和降水的 **2000 年**文件仍待补齐。处理累计量前，按实际下载请求核对 00 UTC 归属、跨月接续、累计类型和蒸发符号。获取入口见 [Copernicus CDS](https://doi.org/10.24381/cds.e2161bac)。

## 入库与验收

原始文件按产品、变量组或版本存放，保留下载时的文件名。流水线只读本目录，中间产物写入 `data/interim`。数据及归档遵循各提供方许可。

M1 在正式使用前核查文件可读性、时间坐标完整性、空间覆盖、单位与符号、累计类型、填充值、QA 和数值范围。逐文件登记来源或请求编号、版本、覆盖、字节数、SHA-256 和许可，并记录原生字段映射。站点、研究区矢量和可选环流按 SOP 分别验收。 [原始文件登记表](../../metadata/source_file_manifest.csv) · [变量映射表](../../metadata/source_variable_map.csv) · [预处理 SOP](../../docs/论文方向与构想/黄土高原FD-WT_v1.3.1_分产品原生变量与预处理SOP附录.md)
